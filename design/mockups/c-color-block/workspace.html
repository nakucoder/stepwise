What's happening

Compare a[2] = 5 with a[3] = 8. Since 5 ≤ 8 the pair is in order: no swap, j advances. Is 5 bigger than 8? No. They're already in the right order, so they stay put.

def bubble_sort(a):    n = len(a)    for i in range(n - 1):        swapped = False        for j in range(n - 1 - i):            if a[j] > a[j + 1]:                a[j], a[j + 1] = a[j + 1], a[j]                swapped = True        if not swapped:            break    return a
